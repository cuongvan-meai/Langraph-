## Thứ tự đọc code để học (khoảng 1-2 giờ)

1. `tools.py`: 3 tool + chunking. Chú ý docstring, đó là thứ LLM đọc để chọn tool.
2. `ingest.py`: quen thuộc, chính là pipeline RAG bạn đã làm.
3. `agent.py`: đọc sơ đồ ở đầu file, rồi tới `State`, `llm_node`, `tools_node`, `should_continue`, `build_graph`.
4. `test_offline.py`: xem 4 kịch bản để hiểu Agent đi qua các node thế nào.

## Câu hỏi tự kiểm tra (trả lời bằng lời của bạn)

1. State của graph chứa gì, node trả về gì?
2. `should_continue` quyết định điều gì, nhìn vào đâu để quyết định?
3. Vì sao sau node `tools` phải có edge quay lại `llm`?
4. `MAX_STEPS` giải quyết vấn đề gì so với `while True`?
5. Nếu LLM gọi tool không tồn tại thì chuyện gì xảy ra?

## Thử nghiệm để hiểu sâu

- Hỏi: “Chào bạn”, “Giai đoạn 7 học gì?”, “Mình đang ở đâu?”, “Còn bao nhiêu % nữa là xong?”, “Tuần này nên học gì?”
- Xem dòng 🔧 in ra để biết Agent gọi tool nào, theo thứ tự nào.
- Xóa docstring của 1 tool rồi hỏi lại: Agent chọn tool có kém đi không?

## Nếu qwen3:4b chạy sai

Model 4B nhỏ nên có lúc gọi nhầm hoặc quên gọi tool. Đây là hiện tượng bình thường, không phải lỗi code. Cách xử lý: làm rõ docstring tool, sửa SYSTEM_PROMPT, hoặc thử model lớn hơn (qwen3:8b).
